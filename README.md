# IBM Weekly Stock Market Dataset

## Description
This repository contains historical weekly stock market data for IBM (International Business Machines Corporation), collected using the Alpha Vantage API.

## Dataset Features
- **Date:** Date of the weekly observation
- **Open:** Opening stock price
- **High:** Highest stock price during the week
- **Low:** Lowest stock price during the week
- **Close:** Closing stock price
- **Volume:** Number of shares traded during the week

## Data Source
Alpha Vantage API

## Data Frequency
Weekly

## File
`IBM_weekly_market_analysis.csv`

## Purpose
This dataset can be used for learning data analysis, exploring historical stock price trends, and practicing Python and Pandas.

**Note:** This dataset is for educational and analytical purposes only, not financial advice.
